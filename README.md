# 업비트 자동매매 프로그램

업비트 API를 사용하여 현재 보유 자산을 조회하고 자동으로 암호화폐를 매매하는 Python 프로그램입니다.

## 기능

### 자산 조회 기능
- 현재 보유 중인 모든 자산 조회
- 원화 및 암호화폐 잔고 표시
- 암호화폐의 현재 시세 및 평가금액 계산
- 평균 매수가 대비 손익 계산
- 총 자산 평가액 계산

### 자동매매 기능
- 설정된 코인 종목 자동 매매
- 기술적 분석 기반 매매 신호 생성
- 이동평균 교차 전략 (골든크로스/데드크로스)
- 실시간 가격 모니터링
- 자동 매수/매도 주문 실행

## 설정 방법

### 코인 종목 및 매매 설정
프로그램 상단의 설정 구간에서 다음 항목들을 수정할 수 있습니다:

```python
# ================== 설정 구간 ==================
# 매매할 코인 종목 설정 (KRW- 제외하고 입력)
TARGET_COIN = "BTC"  # 예: BTC, ETH, ADA, DOGE 등

# 매매 설정
BUY_AMOUNT = 10000  # 한 번에 매수할 금액 (원화)
SELL_RATIO = 1.0    # 매도 비율 (1.0 = 100%, 0.5 = 50%)

# 체크 주기 (초)
CHECK_INTERVAL = 60  # 60초마다 가격 체크
# ==============================================
```

## 사용 방법

### 1. 업비트 API 키 발급

1. [업비트 웹사이트](https://upbit.com)에 로그인
2. 마이페이지 → Open API 관리
3. API 키 발급 (자산 조회 권한 필요)
4. Access Key와 Secret Key 저장

### 2. API 키 설정

**방법 1: Key.txt 파일 사용 (가장 편리함)**
```
APIKey/Key.txt 파일을 다음과 같은 형식으로 작성:

Access Key: your_access_key_here
Secret Key: your_secret_key_here
```

**방법 2: 환경 변수 설정**
```bash
# Windows (PowerShell)
$env:UPBIT_ACCESS_KEY="your_access_key_here"
$env:UPBIT_SECRET_KEY="your_secret_key_here"

# Windows (Command Prompt)
set UPBIT_ACCESS_KEY=your_access_key_here
set UPBIT_SECRET_KEY=your_secret_key_here

# Linux/Mac
export UPBIT_ACCESS_KEY="your_access_key_here"
export UPBIT_SECRET_KEY="your_secret_key_here"
```

**방법 3: 프로그램 실행 시 직접 입력**
프로그램을 실행하면 API 키 입력을 요구합니다.

**우선순위**: Key.txt 파일 → 환경 변수 → 직접 입력

### 3. 프로그램 실행

```bash
python autotrading.py
```

실행 후 모드를 선택할 수 있습니다:
- **1. 자산 조회만**: 현재 보유 자산만 조회하고 종료
- **2. 자동매매 시작**: 설정된 코인으로 자동매매 시작

## 주의사항

### 보안 관련
- API 키는 절대 타인과 공유하지 마세요
- API 키가 노출되지 않도록 환경 변수 사용을 권장합니다
- **자동매매용 API 키는 주문 권한이 필요합니다**

### 투자 관련
- **이 프로그램은 교육 및 연구 목적으로 제작되었습니다**
- **실제 투자에 사용할 경우 손실 위험이 있습니다**
- **충분한 테스트 없이 실제 자금으로 사용하지 마세요**
- **소액으로 테스트한 후 사용하시기 바랍니다**

### 기술적 제한
- 업비트 API 호출 제한을 준수하세요 (초당 10회, 분당 600회)
- 매매 알고리즘은 기본적인 이동평균 교차 전략만 구현되어 있습니다
- 시장 급변 상황에서는 예상과 다른 결과가 나올 수 있습니다

## 오류 해결

### Import 오류
```
ImportError: No module named 'requests'
```
→ `pip install requests PyJWT` 명령어로 라이브러리를 설치하세요

### API 오류
```
401 Unauthorized
```
→ API 키가 올바른지 확인하세요

### 네트워크 오류
→ 인터넷 연결 상태를 확인하세요
